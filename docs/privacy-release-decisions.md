## 다음 정책 결정: 댓글 삭제와 관리자 숨김 구분

현재 일반 삭제는 deleted_at만 바꾸어 본문과 작성자 연결이 DB에 남는다.
탈퇴는 본문을 비우고 작성자 연결을 제거하지만 다른 회원의 답글은 남긴다.
관리자 숨김은 원래 복원을 위한 기능이다. 일반 삭제와 동일하게 처리하면 복원이 깨진다.

사용자 승인 완료·로컬 구현 완료(외부 배포 전):

1. **사용자 직접 삭제:** 요청 성공 시 본문·작성자 연결·재시도 식별값을 제거한다.
   삭제 안내와 답글 연결에 필요한 최소 정보만 남기고 타인의 답글은 보존한다.
   작성자가 직접 삭제한 본문은 관리자도 복원할 수 없다는 안내를 함께 넣는다.
2. **관리자 숨김:** 30일간 복원할 수 있도록 보관하고, 이후 본문·작성자 연결을 제거한다.
   부모가 숨겨진 동안 답글 공개 범위는 기존 정책을 유지한다. 타인 답글을 연쇄 파기하지 않는다.
   30일은 법정 보존 기간이 아니라 운영자 승인이 필요한 제안이다.
3. **회원 탈퇴:** 2026-09-13 추가 승인으로 즉시 삭제를 대체한다. 30일간 계정을 중지하고
   복구 목적으로 보관한다. 같은 Google sub 인증 후 명시적 확인으로 복구하며 마감 이후 영구 정리한다.
   Google 권한 철회는 필수다. 직접 삭제/관리자 숨김은 복구로 되돌리지 않는다.
   상세 정책과 현재 배포 조건은 account-withdrawal-google-design.md를 따른다.

구체적인 정책 제안에 대한 사용자의 '진행' 승인 후 구현했다.
가상 DB에서 경계 시각·삭제/숨김/복원·다른 회원 답글·추천 집계 회귀 검사를 추가했다.
운영 DB의 기존 데이터를 지금 지우는 작업은 수행하지 않는다.
