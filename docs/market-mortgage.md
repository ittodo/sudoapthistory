# 시장동향 주담대 평균금리 비교

> 문서 역할: **현재 지침·구현 설명** · [문서 목록](README.md)

## 앞으로 지킬 운영 지침

- 한국은행 ECOS `121Y006`(예금은행 대출금리·신규취급액 기준)의 `BECBLA0302`(주택담보대출), 월간 `M`, 연리%만 사용한다. 전국 신규 실행 대출의 가중평균이며 개별 은행 상품 견적이나 특정 개인의 적용 금리가 아니다.
- 계약 가격 그래프에는 실제 통계 대상월로 정렬한다. 최신 기준월을 표시하고 미발표·제공 이전 월은 null로 유지한다. 이전 금리로 채우거나 추정하지 않는다. 전국 공통 자료이므로 지역·면적 선택은 금리를 바꾸지 않는다.
- ECOS 응답에 발표일이 없으므로 `checkedAt`은 수집 확인일만 의미한다. 이를 발표일로 표시하거나 당시 사용 가능한 자료였다고 해석하지 않는다.
- `node tools/collect-mortgage.mjs`는 기존 마지막 대상월부터 24개월을 다시 확인한다. 최초 및 `--full`은 2001-09부터 전체를 확인한다. 공개 sample API의 요청당 10건 제한을 준수해 직렬 페이지 조회하며 별도 키·예약·DB를 만들지 않는다.
- 응답 통계/항목/단위, 페이지 총수·범위·연속성, 기존 행 소실을 검사한다. 실패 시 기존 정상 파일을 보존하며 동일 자료는 다시 쓰지 않는다. 과거 정정 전체 확인은 `--full`로 수행한다.
- Production 빌드에서 최신 자료를 수집한다. 수집 실패는 CI 경고로 기록하고 마지막 검증 자료를 사용하되 빌드에서 파일을 반드시 다시 검증한다. 금리 다운로드 실패가 가격 조회를 막지 않게 한다.
- 기존 배포 잠금·검증을 유지한다. 공개 파일은 동일 배포 manifest로 검증한다. 주택 거래·환산율·캐시는 변경하지 않는다. COFIX 파일과 수집기·표시 코드는 제거한다.

## 실제 구현

`data/market-rates/mortgage.json`의 schema 1은 source/statCode/itemCode/unit/basis/checkedAt/pages/rows를 저장한다. pages는 공식 요청 URL과 응답 SHA-256, rows는 `{month,rate}`이다. 발표일은 저장하지 않는다.

`js/market-mortgage.js`는 매매·전월세 시장동향 가격 그래프에 단일 금리선과 오른쪽 연 % 축을 붙인다. 월별 전국 평균을 선택 표시하며 다운로드는 한 번 공유한다. 기존 세 종류 COFIX 선택은 제거한다.

`node --test tools/test-market-mortgage.mjs`로 통계 오선택·결측·중복·실패 보존·정정·동일 입력·월 정렬·빌드 검증을 확인한다. 실제 수집 범위와 검증 결과는 아래 기록에 추가한다.

최초 수집(2026-10-02): 2001-09~2026-08 연속 300개월, 최신 연 4.66%, JSON 15,346바이트. 공개 sample API 요청 30회로 전체를 확보했다. 배포 전 로컬 구현·자료이며 운영 공개 완료를 뜻하지 않는다.

검증: 시장동향·금리 테스트 19개 PASS. 실제 자료를 다시 수집한 결과 UNCHANGED(300개월)이며 파일 바이트를 재작성하지 않았다. 두 차트의 기존 가격선, 월 정렬, 금리 표시 전환과 한 번 다운로드를 검증했다.
