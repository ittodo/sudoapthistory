# 전월세 월간 시장 동향

`/market/`의 전세·월세는 전용 화면과 worker를 사용한다. 매매와 Chart.js 생성기 및 기준월 표시를 공유하며, 다른 전월세 메뉴는 기존 rental-app을 유지한다.

## 계산

- 전세: 보증금. 월세 기본값: 월세 + 보증금 × 연 환산율(%) / 1200.
- 보증금 환산: 보증금 + 월세 × 1200 / 연 환산율(%).
- 원본 거래에 기록된 계약 월·지역별 환산율과 적용 월을 그대로 사용한다. 공식 환산율이 없는 거래는 건수에만 포함한다.
- 해제 거래는 파생 자료 생성 시 제외한다. 평균과 중위값은 필터를 통과한 개별 거래에서 계산한다. 평당가는 거래별 금액 × 3.305785 / 전용면적이다.
- 가격대는 총액 기준이며 경계값은 하위 구간에 포함한다. 평당가 모드에서도 분류와 금액 합계는 총액을 사용한다.
- 누적 막대의 환산 불가 구간을 포함한 합계는 전체 거래건수와 일치한다. 가격은 자료가 없으면 null로 두어 선을 연결하지 않는다.

## 자료와 캐시

`build-rental-market-cache.mjs`가 기존 월별 거래 shard의 해시를 검증하고 `data/rental/market-cache/YYYY-MM-REGION.bin`을 생성한다. 출력은 `cloudflare/dist/rental-market-cache-v1`에 보관하며 원천 DB를 변경하지 않는다. 배포 빌드와 로컬 미리보기 모두 이 생성기를 사용한다.

압축 JSON schema 1의 각 row: 단지 인덱스, 면적, 계약일, 보증금, 월세, 계약 구분, 층, 연 환산율(%), 환산율 적용 월, 원천 거래 ID. 인덱스에는 원본 버전·입력 해시·출력 해시와 매매의 월 번호 기준 연도가 포함된다.

Worker는 다운로드를 최대 3개로 제한하고 각 월의 지역 파일은 순차 요청한다. 조건을 바꿔도 새 조회에 필요한 진행 중 다운로드는 공유한다. 원본 버전이 일치하지 않는 파생 캐시는 사용하지 않고 검증된 원본 월별 파일로 대체한다. 최근 원본 row 12개 shard, 필터별 집계 800개월을 메모리에 보관하며 두 환산 기준·평당가·가격대 집계를 함께 캐시한다. 브라우저 디스크에는 압축 자료·대체 원본·단지 목록을 해시별로 저장하며, 전체 보유 기간의 두 버전이 들어갈 수 있도록 한도를 잡는다(최소 1,024개, 보유 월수 × 6 + 2). 브라우저가 저장 공간을 제공하지 않거나 저장 자료를 삭제한 경우에는 다시 내려받을 수 있다. 진행 문구는 다운로드와 캐시 재계산을 구분해 통계 계산으로 표시한다.

URL의 `marketRentMetric=monthly|deposit`은 시장 화면 전용이다. 기존 `from`, `to`, `m`, `mExact`, `r`, `gu`, `pm`, `tier` 해시를 유지한다. 전월세의 시작 연도와 관계없이 기존 `m`은 매매 시작 연도로부터 실제 연월로 바꾼다.

## 검증

- `npm run test:market`: 환산, 평당가, 중위값, 구간 경계, 필터 일관성, 링크 호환, 캐시 무결성·재사용·재시도.
- `node tools/test-rental-model.cjs` 및 `node tools/test-rental-worker.cjs`: 기존 전월세 회귀 검사.
- `npm run test:site`, `npm run build`: 기존 사이트 및 전체 패키징 검증.
- 로컬 미리보기에서 매매·전세·월세, 5개 지역 제한, 환산 토글, 가격대, 390px 화면, 빈 결과 및 URL 복원을 확인한다.

운영 배포는 별도 절차로 수행한다.
