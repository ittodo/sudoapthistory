# 전월세 지도 UI와 성능

## 2026-09-21 날짜 변경 시 이전 다운로드 취소

- 지도·가격대 통계의 새 조회는 필요 파일 목록을 먼저 계산해 사용하지 않는
  이전 월 다운로드를 취소한다. 초기화 대기 중 취소된 조회는 다운로드를 시작하지 않는다.
- 같은 달 조회와 다음 달로 이동할 때 이미 받고 있는 파일은 공유한다.
  완료된 파일 캐시와 현재 조회에 유효한 다음 달 예열은 유지한다.
- 새 조회는 높은 다운로드 우선순위를 사용한다. 통계 날짜·기간 변경은 즉시
  조회하며, 오래된 응답·취소 오류는 새 화면에 반영하지 않는다.
- 지연된 이전 월 요청을 해제하지 않고 새 지도·통계 조회가 완료되는 테스트,
  같은 달 파일 공유와 초기화 대기 조회 생략 테스트를 통과했다.
  새 월의 첫 다운로드·압축 해제 시간 자체는 남는다.

## 2026-09-21 공통 상세 재사용과 가격 카드 위치

- 전월세 카드는 기존 `NodoApartmentLinks` 상세 창과 `NodoRent` 탭을 연다.
  별도 지도 상세 패널과 스타일을 제거하고 단지·면적·연도·유형을 전달한다.
- 최근 자료에 없는 연도는 기존 rental worker의 검증된 history 로더를 재사용한다.
  공통 상세의 계약표·차트는 유지하고 승인된 원천 ID만 연결한다.
- 매매·전월세·시간 지도는 `NodoMapModel.labelPosition`을 공유한다.
  필지 상단에서 26~40px 내려온 위치에 카드를 배치하며 작은 필지나 경계가
  없는 단지는 중심에서 36px 위에 표시한다. 실제 좌표·경계는 변경하지 않는다.
- 수지푸르지오월드마크 2017년 전세 84.26㎡ 계약 9건과 공통 상세 탭을
  브라우저에서 확인했다. 지도 위치 계산과 승인 ID의 과거 계약 조회를 검사한다.

## 2026-09-21 지도 범위별 전달과 단지 상세

- 지도 작업 스레드에서 원천 단지별 최신 대표 계약을 선택하고 현재 지도
  범위의 단지만 화면에 전달한다. 같은 날 대표 계약은 거래 ID로 결정하며,
  거래 집계와 행정구역 요약은 지도 범위로 잘리지 않는다.
- 매매의 행정 경계·지역 카드 구현을 공유한다. 전세는 보증금, 월세는 원월세
  또는 월 환산액으로 단지별 최신 대표값의 평균을 표시한다. 확대하면 단지
  가격 카드를 표시하고 선택 시 실제 연간 계약 내역을 지도 안에서 읽는다.
- 매매 publicId가 없는 전월세 단지도 원천 ID로 상세를 연다. 지도 위치·확대와
  시간 재생 범위·간격·속도를 URL에서 복원한다. 화면 크기 변경 시 지도를 갱신한다.
- 월별 자료 URL은 파일 내용 해시를 사용하여 다른 파일만 갱신된 배포에서도
  변하지 않는다. 지도에 필요 없는 장기 통계 요약은 요청하지 않는다.
- 실제 2026-09-18 월세 환산 자료: 총 137,908개 상태의 집계 유지. 작업 스레드
  응답은 기존 118,530개 점 / JSON 문자열 26,388,870자에서 구로구 대표 화면
  209개 단지 / 135,702자로 감소했다(약 99.5%). 같은 달 날짜 이동 계산은
  약 0.1초. 이 수치는 네트워크와 브라우저 렌더링을 포함한 전체 시간은 아니다.
- 최초 조회는 압축 월별 상태 자료 약 13.2MB를 여전히 읽는다. 월 경계의 최초
  다운로드·압축 해제 비용도 남으며, 재생 중 다음 달 예열과 캐시를 유지한다.
- 검증: rental model/worker, map model/parcels, site layout 검사 및 전체 자산
  패키징 통과. 실제 브라우저에서 원래 URL 위치, 지역·단지 카드, 우남푸르미아
  계약 상세, 전세 전환, 날짜 전후 이동, 9월 1→8→15일 주간 재생 종료 확인.
  390px 화면의 본문·지도 컨테이너 너비는 390px이며 페이지 가로 넘침이 없다.

전월세 지도는 매매와 같은 전체 너비의 검색줄 → 날짜·재생줄 → 지도 순서로 구성한다.
면적·보증금·월세·계약 구분과 환산 비교는 필터 패널에서 조절한다.
시군구 목록은 선택한 시도에 맞추며, 지도 날짜는 실제 수집된 마지막 계약일까지만 허용한다.
좁은 화면에서는 조작부를 줄바꿈하고 남은 높이를 지도에 배정한다.

## 계산 경로

- 월별 상태 파일은 시도별로 동시에 읽고 기존 SHA-256 검증을 유지한다.
- 시도별 현재 월의 마지막 거래 상태를 보관한다. 앞으로 이동하면 새 거래만 적용하고,
  뒤로 이동하면 적용 내역을 되돌린다. 월이 바뀌면 해당 월의 시작 상태로 교체한다.
- 전세/월세와 계약 구분은 별개의 상태 키를 유지한다. 필터·거래 유형 전환은 같은 자료를 재사용한다.
- 지도 조회에서는 목록 정렬, 일별 차트, 지역·단지 순위, 히스토그램을 만들지 않는다.
- 슬라이더는 마지막 입력을 모아서 처리하고, 진행 중인 요청보다 오래된 결과는 표시하지 않는다.

## 검증 (2026-09-20)

### 재생 중 다음 달 미리 준비

- 현재 달을 표시하면 별도 `prefetch` 요청으로 다음 달의 선택 지역 자료를 낮은 네트워크 우선순위로 내려받고, 해시 검증과 압축 해제까지 작업 스레드에서 수행한다. 재생 타이머는 이 요청을 기다리지 않는다.
- 현재 달과 다음 달을 함께 보관하도록 지도 자료 캐시는 최대 6개 지역·월 파티션으로 제한한다. 현재 조회 중인 자료는 예열 과정에서 밀어내지 않는다. 전체 재생 기간을 한꺼번에 메모리에 올리지 않는다.
- 월 경계를 넘을 때 이미 완료됐거나 진행 중인 요청을 재사용한다. 준비 요청은 지도 조회의 최신 요청 번호를 바꾸지 않는다.
- 정지·범위 변경·필터 변경 시 필요 없는 백그라운드 요청을 취소한다. 화면 조회가 이미 필요로 하는 요청은 유지한다. 실패한 예열 자료는 실제 이동 시 다시 요청한다.
- 재생 중에는 `다음 달 자료를 미리 준비하는 중…` / `다음 달 자료 준비 완료`를 표시한다. 마지막 달과 정지 상태에서는 숨긴다.
- 빠르게 정지 후 다시 재생해도 이전 재생의 완료 콜백이 추가 타이머를 만들지 않는다.

통합 테스트에서 현재 월 유지, 진행 중인 예열 요청 공유, 정지 시 취소, 전면 조회 보호, 실패 후 재시도, 선택 지역·종료 월 제한을 검증했다. 실제 로컬 브라우저에서 2026-01-01 지도 재생 중 다음 달 준비 완료를 확인했고, 월 단위로 3월까지 이동해 종료하는 것을 확인했다. 첫 조회 및 지도 계산·그리기 시간은 여전히 필요하다.

로컬 실제 자료로 작업 스레드 계산 시간을 비교했다. 네트워크 전송, 브라우저 메시지 복사,
지도 그리기 시간은 아래 수치에 포함하지 않는다.

| 작업 | 변경 전 | 변경 후 |
|---|---:|---:|
| 전세 첫 지도 조회 | 3,571 ms | 1,397 ms |
| 다음 날짜 | 2,899 ms | 57 ms |
| 다음 날짜 한 번 더 | 3,050 ms | 63 ms |
| 이전 날짜 | 2,976 ms | 51 ms |

각 결과의 단지·면적·계약 구분·날짜·보증금·월세·가격 판정·표시 가격을 정렬해
해시로 대조했으며 모두 일치했다. 같은 월의 반복 조회에는 추가 파일 요청이 없었다.

`node tools/test-rental-model.cjs`와 `node tools/test-rental-worker.cjs`로 이름 변환,
필터, 앞으로/뒤로 재생, 월 경계 이동, 계약 구분과 유형 변경, 자료 재사용을 검증한다.
브라우저에서는 검색/필터, 날짜 이동, 주간 재생 및 종료, 현재 지도,
1280×720 / 390×844 화면에서 지도의 크기와 가로 넘침을 확인했다.


## 월세 지도 환산 옵션 노출 (2026-09-20)

접힌 필터 안에 있던 월 환산액 체크박스를 지도 날짜·시군구와 같은 상단 줄로 옮겼다. 선택하면 지도 설명에 환산 계산식을 표시하고, 단지 툴팁·팝업 금액에 `월 환산`을 붙인다. 팝업은 원래 보증금·월세와 해당 계약에 적용한 환산율·기준 월도 함께 표시한다. 전세에서는 옵션을 숨긴다.

로컬 월세 지도에서 필터를 닫은 상태로 전환, 설정 복원, 390px 모바일 배치를 확인했다. 바비엥3(65.71㎡, 2026-09-17) 팝업은 보증금 20,000만원 / 월세 160만원 / 연 4.7%(2026-07) / 월 환산 238.33만원으로 표시됐다. worker 검사에 원월세와 환산액 전환, 환산율·기준 월 전달 및 재전환 결과 일치를 추가했다.

## 묶음 지도 캐시 (2026-09-21)

기존 월초 상태와 월중 변경 기록을 Cloudflare 자산 빌드에서 재사용한다. 운영 DB와 원본 파일을 변경하지 않으며, `tools/build-rental-map-cache.mjs`가 `data/rental/map-cache/월-시도-유형.bin`을 생성한다. 한 파일에 해당 지역의 여러 단지·평형·계약 구분을 모두 담는다. 일별 상태를 중복 저장하지 않는다.

지도에 필요한 11개 필드만 저장하고, 거래 ID는 원본 문자열 정렬 순위를 사용해 같은 날짜의 대표 거래 선택을 유지한다. 전세와 월세 파일을 분리해 선택한 유형만 전송한다. 지도 필터·단지 대표값·지역 평균·날짜 이동은 기존 worker 계산을 사용한다. 가격대 통계와 상세 계약 내역의 원본 자료 경로는 유지한다.

캐시 인덱스는 원본 manifest 버전과 입력 파일 해시가 일치할 때만 사용한다. 없거나 오래된 인덱스는 기존 상태 파일로 대체한다. 개별 파일은 SHA-256 검증 후 브라우저 Cache Storage에 최대 18개 보관하며, 재방문 시 같은 해시의 파일을 재사용한다. 손상된 저장 파일은 다시 받고 저장 공간을 사용할 수 없으면 일반 다운로드로 동작한다. 메모리는 기존 최대 6개 지도 파일 제한을 유지한다. 다른 달·유형으로 이동하면 불필요해진 다운로드를 취소한다.

실제 2017-06 / 2026-09 자료에서 앞으로·뒤로 날짜 이동, 전세·월세, 계약 구분, 면적, 가격 판정, 환산 옵션, 지도 영역을 조합한 96개 결과가 원본 계산과 일치했다. 수도권 3개 지역의 월별 지도 파일 합계는 아래와 같다. 공통 카탈로그·초기화 자료·지도 타일은 제외한 압축 파일 크기이며, 로딩 시간 자체를 측정한 수치는 아니다.

| 월 | 기존 | 전세 캐시 | 월세 캐시 |
|---|---:|---:|---:|
| 2017-06 | 4,287,849 B | 928,303 B | 842,907 B |
| 2026-09 | 13,164,979 B | 2,576,627 B | 3,000,585 B |

139개월 캐시는 834개 데이터 파일과 인덱스 1개로 구성된다. 자동 검사 `node --test tools/test-cloudflare-rental-cache.mjs`는 계산 일치, 재빌드 재사용, 입력·저장 파일 손상, 브라우저 재사용, 저장 실패, 오래된 인덱스와 이전 요청 취소를 검증한다.
