# 전월세 지도 UI와 성능

전월세 지도는 매매와 같은 전체 너비의 검색줄 → 날짜·재생줄 → 지도 순서로 구성한다.
면적·보증금·월세·계약 구분과 환산 비교는 필터 패널에서 조절한다.
시군구 목록은 선택한 시도에 맞추며, 지도 날짜는 실제 수집된 마지막 계약일까지만 허용한다.
좁은 화면에서는 조작부를 줄바꿈하고 남은 높이를 지도에 배정한다.

## 계산 경로

- 월별 상태 파일은 시도별로 동시에 읽고 기존 SHA-256 검증을 유지한다.
- 시도별 현재 월의 마지막 거래 상태를 보관한다. 앞으로 이동하면 새 거래만 적용하고,
  뒤로 이동하면 적용 내역을 되돌린다. 월이 바뀌면 해당 월의 시작 상태로 교체한다.
- 전세/월세와 계약 구분은 별개의 상태 키를 유지한다. 필터·거래 유형 전환은 같은 자료를 재사용한다.
- 지도 조회에서는 목록 정렬, 일별 차트, 지역·단지 순위, 히스토그램을 만들지 않는다.
- 슬라이더는 마지막 입력을 모아서 처리하고, 진행 중인 요청보다 오래된 결과는 표시하지 않는다.

## 검증 (2026-09-20)

### 재생 중 다음 달 미리 준비

- 현재 달을 표시하면 별도 `prefetch` 요청으로 다음 달의 선택 지역 자료를 낮은 네트워크 우선순위로 내려받고, 해시 검증과 압축 해제까지 작업 스레드에서 수행한다. 재생 타이머는 이 요청을 기다리지 않는다.
- 현재 달과 다음 달을 함께 보관하도록 지도 자료 캐시는 최대 6개 지역·월 파티션으로 제한한다. 현재 조회 중인 자료는 예열 과정에서 밀어내지 않는다. 전체 재생 기간을 한꺼번에 메모리에 올리지 않는다.
- 월 경계를 넘을 때 이미 완료됐거나 진행 중인 요청을 재사용한다. 준비 요청은 지도 조회의 최신 요청 번호를 바꾸지 않는다.
- 정지·범위 변경·필터 변경 시 필요 없는 백그라운드 요청을 취소한다. 화면 조회가 이미 필요로 하는 요청은 유지한다. 실패한 예열 자료는 실제 이동 시 다시 요청한다.
- 재생 중에는 `다음 달 자료를 미리 준비하는 중…` / `다음 달 자료 준비 완료`를 표시한다. 마지막 달과 정지 상태에서는 숨긴다.
- 빠르게 정지 후 다시 재생해도 이전 재생의 완료 콜백이 추가 타이머를 만들지 않는다.

통합 테스트에서 현재 월 유지, 진행 중인 예열 요청 공유, 정지 시 취소, 전면 조회 보호, 실패 후 재시도, 선택 지역·종료 월 제한을 검증했다. 실제 로컬 브라우저에서 2026-01-01 지도 재생 중 다음 달 준비 완료를 확인했고, 월 단위로 3월까지 이동해 종료하는 것을 확인했다. 첫 조회 및 지도 계산·그리기 시간은 여전히 필요하다.

로컬 실제 자료로 작업 스레드 계산 시간을 비교했다. 네트워크 전송, 브라우저 메시지 복사,

## 월세 지도 환산 옵션 노출 (2026-09-20)

접힌 필터 안에 있던 월 환산액 체크박스를 지도 날짜·시군구와 같은 상단 줄로 옮겼다. 선택하면 지도 설명에 환산 계산식을 표시하고, 단지 툴팁·팝업 금액에 `월 환산`을 붙인다. 팝업은 원래 보증금·월세와 해당 계약에 적용한 환산율·기준 월도 함께 표시한다. 전세에서는 옵션을 숨긴다.

로컬 월세 지도에서 필터를 닫은 상태로 전환, 설정 복원, 390px 모바일 배치를 확인했다. 바비엥3(65.71㎡, 2026-09-17) 팝업은 보증금 20,000만원 / 월세 160만원 / 연 4.7%(2026-07) / 월 환산 238.33만원으로 표시됐다. worker 검사에 원월세와 환산액 전환, 환산율·기준 월 전달 및 재전환 결과 일치를 추가했다.
