# 기간별 매매와 지도 재생

> 문서 역할: **기능·구현 설명** · [문서 목록](README.md)
> 현재 운영·공개 자료 계약은 문서 목록의 기준 문서를 따릅니다. 날짜·건수·성능 수치는 해당 검증 조건의 기록입니다.


## 앞으로 지킬 화면·자료 규칙

공통 메뉴의 거래 목록 진입점은 `/trades/daily/`의 **기간별 실거래**다.
별도 실거래가 메뉴와 기존 탐색기 이동 링크는 표시하지 않는다.
매매·전세·월세 모두 기간을 지정하지 않은 진입은 월간으로 시작한다.
URL에 지정한 일간·주간·월간 조회는 유지한다. 다른 페이지에서 저장한 전월세
조회 단위는 기간별 실거래의 첫 진입 기본값을 바꾸지 않는다.

기간별 거래와 지도 재생은 공통 매매 자료의 번호표·거래·상태를 읽습니다. 단지 키에 지역을 포함하고 정확 면적을 유지합니다. 해제·사라짐 내역과 가격 계산 적격 여부를 구분합니다. 자료 manifest/버전/해시 불일치는 정상 결과로 표시하지 않습니다.

schema 3의 공통 거래는 지역·분기 PGHOUSE1 형식입니다. 지도 상태는 지역·연도 PGSTBND1 파일 안에 매매·전월세 PGSTATE1 구간을 둡니다. 필요한 종류만 부분 조회하며, 과거 기준/overlay나 전역 번호 호환표를 새로 만들지 않습니다. [공통 저장 계약과 전환 상태](../../15_26/docs/housing-packed-storage.md#지도-상태의-연도-묶음)

화면 요청은 선택 지역·기간에 필요한 자료만 읽고 완료 캐시를 재사용합니다. 오래된 응답이 새 날짜/조건 화면을 덮어쓰지 않도록 합니다. 조회 실패, 자료 갱신 중, 조건에 맞는 거래 없음은 서로 구분합니다.

## 월별 매매 목록의 다운로드

기존 `/trades/` 주소는 저장된 링크의 호환을 위해 유지한다.
새 메뉴에서는 기간별 실거래를 사용한다.

`/trades/`는 첫 페이지를 먼저 표시하고 나머지 페이지를 최대 3개씩 받습니다.
월을 바꾸면 이전 요청을 중단합니다. 응답 본문이 늦게 도착해도 현재 조회와 다른
요청의 결과는 반영하지 않습니다. 같은 월로 돌아와도 새 조회로 구분합니다.

받은 페이지는 페이지 번호별로 보관합니다. 일부 페이지가 실패하면 받은 거래는
유지하며 통계는 `자료 미완료`로 표시합니다. `받지 못한 N개 페이지 다시 받기`는
누락된 페이지만 요청합니다. 재시도 버튼은 상단 상태 안내 바로 아래에 표시합니다.
조회 중, 다운로드 실패, 거래 없음은 별도로 안내합니다.
모든 페이지를 받은 뒤 전체 통계를 계산합니다.
첫 페이지의 404는 자료가 없는 월입니다. 다른 HTTP 오류, 후속 페이지의 404,
잘못된 응답 본문은 다운로드 실패로 처리하고 재시도를 제공합니다.
