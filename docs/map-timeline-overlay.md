# 지도 날짜 조작부 오버레이

2026-09-20: 매매·전세·월세 지도의 날짜와 재생 조작부를 지도 위의 공통 패널로 옮겼다.

- 처음에는 제목과 표시일만 보이며 패널을 펼쳐도 지도 높이는 변하지 않는다.
- 과거 가격 재생은 접힌 상태에서도 시작·정지할 수 있다. 날짜와 재생 상태는 기존 동작과 연결한다.
- Escape로 접고 제목 버튼으로 초점을 돌린다. 내부 시군구 선택창이 Escape를 처리했으면 바깥 패널은 유지한다.
- 펼친 내용만 스크롤하며 지도 확대 버튼과 겹치지 않는다. 자료 오류는 접힌 제목에도 표시한다.
- 매매 지도 범위·자료 안내는 하단에서 차례로 배치한다. 전월세 시군구 선택창은 패널 안에서 펼친다.

로컬 확인: 데스크톱 브라우저에서 320×568, 390×844, 1280×900 화면 크기와 라이트·다크 테마를 확인했다. 실제 휴대폰 검증은 포함하지 않는다. 390×844에서 매매 지도 높이 578px, 전월세 581px이며 펼침·접힘에 따라 줄어들지 않는다. 가로 넘침 없음, 거래 유형 전환, 날짜 변경, 접힌 상태 재생·정지, 시군구 두 곳 선택, 월 환산액 설정을 확인했다.

기존 일별 거래·지도 모델/경계·전월세 모델·캐시 무효화 검사와 타입 검사를 통과했다. 사이트 검사의 로컬 Git 경로 신뢰 오류는 해당 저장소만 신뢰하도록 설정한 뒤 해당 검사 재실행으로 통과했다. 공개 자료·수집 DB·예약 일정은 바꾸지 않는다.
