# 가격대 세대수·거래 회전율

`/stats/?tenure=sale`은 `data/index.json`, `data/price_bands.json`,
`data/tax_revenue_actuals.json`을 읽는다. 생성기는 `tools/build-price-bands.mjs`다.
현재 리뷰 자료로 index를 보강한 뒤 통계를 생성한다.
세대수의 원천과 중복 방지는 [현재 HUB 집계 기준](../../ops-dashboard/housing-review/docs/hub-source.md#공개-평형별-세대수)을 따른다.

세대수는 각 index 행의 `u`다. 단지 전체 `tu`로 대체하지 않는다.
`u`가 없거나 부분 집계인 `up` 행은 세대수 통계에서 제외한다.
목록에는 가격이 있는 미확인 평형도 표시한다.
미확인 세대수는 ‘미확인’, 그에 의존하는 계산은 ‘산정 불가’로 표시한다.
현재 범위의 확인·미확인 평형 수를 화면 상단에 표시한다.

현재 시가총액은 확인 세대수와 최근 실거래 평균가 `lp`를 곱한 합계다.
미확인 평형을 포함한 전체 시장의 시가총액으로 해석하지 않는다.
연도별 추이는 현재 확인된 세대수에 해당 연도의 평균가를 적용한다.
가격이 없는 해는 직전 관측 가격을 이월한다. 최초 관측 전은 제외한다.
이 추이는 해당 연도의 실제 주택 재고를 복원한 값이 아니다.

회전율의 분자와 분모는 동일한 확인 평형 집합이다.
해당 연도의 거래건수를 같은 가격대의 세대수로 나눈다.
별도로 원자료의 전체 거래건수를 표시해 집계 범위를 알린다.
진행 중인 연도는 YTD이며 연환산하지 않는다.
미확인 평형이 있는 범위에서는 공식 전체 세수를 부분 시가총액으로 나눈 비율을 표시하지 않는다.

지역 선택은 통계와 목록에 적용된다. 가격대·평형·단지 검색은 목록에 적용된다.
회귀검사는 `node --test tools/test-cloudflare-price-bands.mjs`로 실행한다.
운영 CI의 기존 `test-cloudflare-*.mjs` 검사에도 포함된다.
