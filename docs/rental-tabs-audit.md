# 전월세 전체 탭 점검 (2026-09-20)

로컬 Miniflare 미리보기에서 매매·전세·월세 전환과 전월세 결과를 확인했다. 운영 배포는 포함하지 않는다.

## 후속 레이아웃 수정

사용자 미리보기에서 1935px 뷰포트의 헤더·본문이 최대 너비 1600px로 가운데 배치되면서, 왼쪽에 붙은 거래 유형 줄과 정렬이 달랐다. 기존 검증의 가로 넘침 검사만으로는 이 여백 문제를 발견하지 못했다. 부동산 공통 화면의 최대 너비 제한을 풀고, 헤더·거래 유형·본문을 동일한 여백(데스크톱 24px, 모바일 12px)에 맞췄다. 본문 시작점은 해당 미리보기에서 192px에서 24px로 변경됐다.

1000px 이하 필터는 열 수를 줄여 배치하며, 표만 내부 가로 스크롤을 사용한다. 2560px·900px·390px 실거래 화면과 390px 전월세 9개 메뉴에서 페이지 가로 넘침 및 화면 밖 필터가 없음을 다시 확인했다. 사용자 미리보기도 새로고침했다.

| 화면 | 확인 결과 |
| --- | --- |
| 단지 검색 | 세 유형 전환, 전월세 순위·계약 표, 매매 관심 순위가 전월세 안에 삽입되던 문제 수정 |
| 지도 | 세 유형 조회, 전월세 전체 너비·날짜 이동·재생, 모바일 지도 |
| 지역·단지 비교 | 세 유형 조회, 지역 비교를 첫 결과로 배치 |
| 시장 동향 | 세 유형 조회, 월별 추이를 첫 결과로 배치 |
| 가격대 통계 | 세 유형 조회, 선택 조건 전체의 가격 분포를 첫 결과로 배치 |
| 실거래가 | 세 유형 조회, 중복 바로가기 제거, 전월세 기간 이동·계약 표 |
| 기간별 실거래 | 세 유형 조회, 일간·주간·월간 전환 |
| 순위 | 매매 관심 순위와 전월세 가격 순위 각각 조회 |
| 단지 상세 | 학마을서원 매매, 전세 23건·월세 36건(2026년), 이전 row=37305 링크 호환 |
| 정책 | 정책 화면 정상 표시, 거래 유형 탭 없음 |

1280px 화면 및 390px 모바일에서 전월세 9개 화면의 가로 넘침과 시군구 숫자 코드가 없음을 확인했다. 월별 전체 조회(2026-09)는 전세 9,896건, 월세 10,511건이다. 지도는 2026-09-17까지 마지막 거래 기준으로 전세 147,696건, 월세 134,887건이다. 단지 상세는 2026년 기준이다. 매매는 기존 메뉴별 집계 기준을 유지한다.

공통 필터는 선택 시도의 시군구만 표시한다. 서울·종로구 선택 후 경기로 변경했을 때 시군구가 전체로 초기화되는 것을 확인했다. 월세 최소 100만원을 조회한 다음 전세로 전환하면 월세 조건을 지우고 전체 전세 결과가 복원된다. 원금액 월세에서는 상승·하락 분류/정렬을 해제한다.

## 계산 및 다운로드

화면에 없는 차트·순위·분포 집계를 생략하고, 정렬 키는 거래마다 한 번만 계산한다. 자료 캐시는 큰 지도 파티션 3개와 그 외 자료 9개를 각각 상한으로 유지한다. 두 달에 걸친 주간 조회도 여섯 지역·월 자료를 재사용한다.

실제 자료를 읽는 Node worker 실험(네트워크 전송·브라우저 렌더링 제외)의 한 실행:

| 조건 | 변경 전 | 변경 후 | 추가 자료 요청 전→후 |
| --- | ---: | ---: | ---: |
| 9월 전세 내역 | 283ms | 165ms | 0→0 |
| 9월 월세 내역 전환 | 261ms | 154ms | 0→0 |
| 8월 31일~9월 6일 주간 | 345ms | 202ms | 6→3 |
| 같은 주간 보증금 정렬 | 283ms | 113ms | 6→0 |

네 조건의 반환 거래 50건에 대해 거래 ID·면적·계약일·금액·판정·변동률의 해시가 변경 전후 일치했다. 네트워크 환경과 브라우저에 따라 실제 체감 시간은 다르다. 지도 실험은 `rental-map.md` 참조.

검증: `node tools/test-rental-model.cjs`, `node tools/test-rental-worker.cjs`. 시군구 변환, 거래 유형 조건 정리, 표시 패널 선택 전후 결과 일치, 주간 자료 재사용, 지도 앞으로/뒤로 이동 및 거래 결과를 검사한다.


## 기간별 실거래 시군구 다중 선택 (2026-09-20)

매매 기간별 실거래와 공통 전월세 화면에 체크박스 선택창을 적용했다. 선택한 시군구는 쉼표로 구분해 기존 URL 필드(g / rental_district)에 저장하며, 어느 한 곳에 속하는 거래를 함께 조회한다. 기존 단일 시군구 URL도 유지된다. 전체 해제, 지역 변경 시 해당 지역 밖 선택 제거, 새로고침 복원을 지원한다. 전월세 지도는 같은 선택창을 쓰며, 매매 지도는 기간별 목록에서 전달받은 복수 지역 조건을 선택 항목에 표시한다.

로컬 브라우저에서 2026년 9월 서울 강북구·도봉구를 검증했다.

| 거래 유형 | 강북구 | 도봉구 | 함께 선택 |
| --- | ---: | ---: | ---: |
| 매매 | 27 | 87 | 114 |
| 전세 | 45 | 69 | 114 |
| 월세 | 30 | 67 | 97 |

매매·전월세 새로고침 복원, 전체 해제, 지역 변경, 지도 이동 후 조건 표시를 확인했다. 모바일 390px에서는 스크롤바를 뺀 실제 너비 375px 안에 선택창이 배치되고 가로 넘침이 없었다. 선택창에서 Escape 키와 선택 완료 버튼으로 닫을 수 있다.

검증: test-daily-model.cjs, test-rental-model.cjs, test-rental-worker.cjs 통과. 복수 지역 OR 조건, 부분 이름 오일치 방지, 82개 선택 URL, 중복 제거, 지역별 선택 정리를 검사한다.
