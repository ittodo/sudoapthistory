# 시장동향 COFIX 비교

> 문서 역할: **현재 지침·구현 설명** · [문서 목록](README.md)

## 앞으로 지킬 운영 지침

- 은행연합회 공시만 사용한다. 대상월과 공시일을 따로 보존하고 월간 가격 그래프에는 대상월로 정렬한다. 공시 전 시점의 투자 판단에 사용 가능한 자료였다고 해석하지 않는다.
- 신규취급액 기준을 기본으로, 잔액·신잔액 기준을 선택한다. 오른쪽 축의 연 %로 표시하며 실제 가산·우대 적용 대출금리가 아니다.
- 제공 시작 이전·미공시·결측 자료는 null로 유지한다. 직전값 채우기·추정·전월세 환산 사용을 하지 않는다. 지역·면적 선택은 전국 공통 금리를 바꾸지 않는다.
- `node tools/collect-cofix.mjs`는 최신 두 공시 연도를 재확인한다. 최초 또는 `--full`은 2010년 이후 모든 공시 연도를 검증한다. 오래된 정정은 `--full`로 반영한다. 실패·행 소실·월 누락이면 기존 정상 파일을 보존한다. 동일 자료는 파일을 다시 쓰지 않는다.
- 기존 Production 빌드에서 최신 공시를 확인한다. 수집 실패는 CI 경고로 남기고 마지막 정상 공시로 빌드한다. 별도 예약·DB·자격증명을 만들지 않는다. 그래프의 금리 다운로드 실패도 가격 조회를 막지 않는다.
- 배포는 [기존 배포 계약](cloudflare-auto-deployment.md)을 따른다. 공개 COFIX 파일도 같은 배포 manifest의 해시로 검증한다.

## 저장·읽기 구현

`data/market-rates/cofix.json`은 schema 1의 작은 전국 공통 파일이다. `source`, `unit`, `basis`, `updatedAt`, 연도별 원문 URL·SHA-256인 `pages`, 그리고 `rows`를 저장한다. 각 행은 `month`, `publishedAt`, `new`, `balance`, `newBalance`이며 금리는 문자열이 아닌 숫자다. 원문 HTML은 공개하지 않는다.

`js/market-cofix.js`가 세 종류를 선택하고 공통 차트의 가격 그래프에만 금리선과 오른쪽 축을 연결한다. 파일은 한 번 다운로드해 지역·기간·면적 변경에 재사용한다. 매매의 YYYY.MM과 전월세의 YYYY-MM을 같은 대상월로 읽는다. 거래량·금액 합계·원본 거래·주택 캐시는 바꾸지 않는다.

## 검증

`node --test tools/test-market-cofix.mjs`는 월별/주간 표 구분, 신잔액 출시 전 결측, 중복·누락·날짜·금리 검증, 실패 시 파일 보존, 두 그래프의 월 정렬을 확인한다. 실제 자료 확보 범위와 공개 검증 결과는 배포 기록에 남긴다.

초기 수집(2026-10-01): 대상월 2010-01~2026-08의 연속 200개월, 세 종류를 합친 JSON 20,887바이트. 최신 공시일은 2026-09-15이며 신규취급액 3.18%, 잔액 3.05%, 신잔액 2.71%다. 정식 빌드에서도 COFIX 데이터 검증을 수행해 손상된 이전 파일이 수집 실패의 대체 자료로 공개되지 않도록 한다.
