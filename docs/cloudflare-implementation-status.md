  Wrangler production dry-run에서 운영 DB·ASSETS 바인딩과 AUTH=false/MAINTENANCE=true 확인.
  최초 dry-run은 로컬 로그 디렉터리 권한 문제로 실패했고 작업 산출물 경로로 로그 위치를 바꾼 뒤 통과했다.
- 실제 운영 Worker 업로드는 아직 하지 않았다. 기존 운영 workflow는 공개 전환 계약 및 공개 URL 검증을
  요구하므로 준비 단계에 그대로 사용하지 않는다. 운영 환경은 main만 허용하며 토큰 추출/권한 완화는 하지 않았다.
  기존 사이트 파일을 건드리지 않는 main의 준비 전용 workflow 추가가 다음 확인 지점이다.

토큰 검증은 가상 RSA 서명으로 정상 토큰 및 잘못된 서명·nonce·대상·발급자·
만료를 시험한다. 실제 Google 계정이나 운영 비밀 설정을 사용한 시험이 아니다.

- 잠금 파일 기반 의존성 재설치 성공. 설치된 의존성 감사 경고 0개.

  재설치해 해결했다. 사용자 프로세스를 일괄 종료하지 않았다.

  OAuth 정상/공격 토큰·동일 계정 재확인·독립 보안 회귀·코드 복구 등.
- 배포/자산/프런트엔드/상태/기존 레이아웃 등 Node 테스트 7개 묶음 통과.

  회원·댓글 읽기 및 새 쓰기 보존 확인. 실제 Cloudflare 버전 복구 시험은 아님.

## 초기 구현 당시 남은 작업 — 최신 진행은 위 외부 상태 참조

1. 시험 배포용 Cloudflare 접근 권한과 GitHub 시험 환경의 비밀 설정 연결.
   토큰은 채팅·Git·공개 산출물에 넣지 않는다. DNS·결제 권한은 시험 배포에 불필요하다.
2. 빈 시험 D1에 새 스키마 적용, 시험 Worker 배포 및 공개 SHA·해시 검증.
3. Google callback·동의 화면 설정, 사용자 직접 일반 로그인 검증.
4. **자동 월 비용 산정·예측은 미구현.** 현재 상태 점검기는 운영자가 입력한
   예상 비용의 7/9달러 수준만 검사한다. 값이 없으면 unavailable로 표시한다.
   실제 비용 수집·임계치별 중복 방지·GitHub 알림 수신 시험은 남아 있다.
5. 유료 운영 승인 여부·전환 시간 확인, 빈 운영 DB·Worker 설정,
   기존 서비스 쓰기 차단·DNS/캐시 전환·사용자 직접 관리자 지정.
6. 예약 작업의 전환된 공개 검증, 실제 Cloudflare 코드 복구 시험,
   오류 알림 수신, 7일 관찰 및 기존 서비스 정리 여부 확인.
