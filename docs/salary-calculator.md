# 연봉·월급 계산기

`/calc/salary.html` — 2026년 7~12월 일반 직장가입자, 퇴직금 제외 급여를 12개월 균등 지급하는 예상 실수령액.

- `js/salary.js`: 원 단위 순수 계산 모델. 보험료와 세금은 항목별 10원 미만 절사하는 추정 방식.
- `js/salary-tax-table.js`: 홈택스 2026.2.27. 개정 별표 2 PDF의 646개 급여 구간, 11개 가족 열 및 월 천만원 세액. 원본 URL·SHA-256·시행일을 데이터에 기록.
- `docs/salary/nts-withholding-2026.pdf`: 검증에 사용한 공식 원본. pdfplumber 표 추출 후 770~10,000천원 구간 연속성과 13열을 검사. PDF 13쪽의 300만원 행 등을 대조.
- 월 천만원 초과는 PDF 마지막 쪽의 구간별 산식. 자녀공제 20,830 / 45,830 / 45,830 + 초과 자녀당 33,330원 적용 후 선택한 원천징수 비율 적용.
- 보험료 신고 보수는 현재 과세 급여로 가정. 국민연금 4.75%, 천원 미만 절사한 소득월액 41만~659만원. 건강보험 3.595%, 근로자 보험료 하한 10,080원·상한 4,591,740원. 장기요양은 건강보험료 × 0.9448/7.19, 고용보험 0.9%.
- 비과세는 세전 급여에 포함. 실제 비과세·기본공제 요건은 사용자가 입력. 산재보험은 사업주 전액 부담.
- 연 환산은 현재 월 결과 × 12이며 해당 연도 실제 총액 또는 연말정산 결정세액이 아님. 가입 제외·지원·감면·휴직·추가 정산·개별 공제는 미반영.

## 검증

`npm run verify:salary` — 모델 테스트 후 `cloudflare/dist/salary-local`에 계산기 의존 파일만 저장. 지역 데이터·전세·월세 캐시 및 공개 배포 산출물은 건드리지 않는다. 미리보기는 소스를 직접 읽으므로 전체 사이트 빌드는 필요 없다.

공식 근거 링크는 계산기 하단에 제공한다. 데이터 갱신 시 원본을 교체하고 구간 연속성·표 예시·고액 산식·가족 공제 및 보험료 상하한 검증을 유지한다.
